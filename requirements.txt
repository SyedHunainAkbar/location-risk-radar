# Runtime dependencies for Streamlit Community Cloud (app only).

# must run in 1 GB RAM. It never trains models and never runs heavy compute.

#   torch, sentence-transformers, spacy (+ en_core_web_sm/lg), scikit-learn,

#   tensorflow, keras. The app reads their precomputed outputs instead.
#

# fastembed (no torch). Cached mode needs no embedding backend at all.
